The current release is **1.5.9**, dated **6 June 2018**, with game data **1.29b**.
Everything below lives under the project's
[SourceForge files area](https://sourceforge.net/projects/uhexen2/files/).

{{< warn >}}
No game assets are included. You need `pak0.pak` and `pak1.pak` from a retail copy of
Hexen II — the port supplies the engine, not the data.
{{< /warn >}}

## Source

| Archive | Contents |
|---|---|
| `hexen2source-1.5.9.tgz` | Engine, HexenWorld and the utilities |
| `hexen2source-gamecode-1.5.9.tgz` | Game code: Hexen II, mission pack, HexenWorld, Siege |
| `hexen2source-oslibs-1.5.9.tgz` | OS-specific headers and libraries |
| `hexen2source-oslibs-source-1.5.9.tgz` | Sources for the bundled third-party libraries |

## Binaries

Packaged builds are available for Linux x86, Linux x86_64, Windows 32-bit and 64-bit,
Mac OS X, OS/2, DOS, AROS, MorphOS and AmigaOS. Each platform has a main package plus
separate HexenWorld client/server and utilities packages. The two shareware demo
versions — November 1997 and August 1997 — are packaged as well.

Release notes for this version:
[Hammer of Thyrion 1.5.9](https://sourceforge.net/projects/uhexen2/files/Hammer%20of%20Thyrion/1.5.9/).

## Game data

The all-inclusive, up-to-date data package is `gamedata-all-1.29b.tgz`. The HexenWorld
pak files and the HexenC source archive are distributed from the same place:
[Hexen2 GameData](https://sourceforge.net/projects/uhexen2/files/Hexen2%20GameData/).
