date: 2008-03-11

description: "The engine runs under Linux on the PlayStation 3."
---

Hammer of Thyrion builds and runs on the PlayStation 3 under Linux. It is the same
PowerPC code path used by other Linux-PPC machines, so nothing special is required
beyond a working Linux install on the console.
